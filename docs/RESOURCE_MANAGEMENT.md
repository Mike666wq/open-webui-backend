# 资源管理实施约定

本文件记录已确认的方向；基础仓库初始化不代表下列功能已完成。

## 页面与权限

- 设置进入完整“资源与存储”页面；保留资源原位置的快捷操作。
- 五区：概览、资源、此设备、回收站、任务与规则。
- 普通用户管理个人资源；管理员查看私人资源账号级统计与策略结果，不在新管理页浏览他人私人正文。
- 覆盖 AI 对话、成员会话、上传、笔记、知识库、分享和本机受管数据；模型权重、系统备份、插件运行文件和数据库压缩不纳入本轮。

## 生命周期

- 手动删除先进入七天回收站；可恢复或二次确认后立即彻底删除。
- 归档、仅本人清空、业务删除、物理空间释放分别显示。
- 私聊／频道清空只改变本人可见历史，保存于后端，同账号跨设备同步；七天可撤销，新消息正常显示。
- 无其他引用的附件随内容回收；有引用的保留并说明原因，最终清理前重新检查。
- 共享资源从普通批量清理排除，单独确认全员及引用影响。
- 置顶／固定默认保护，可明确纳入；恢复内容后公开分享继续暂停，所有者另行开放。
- 临时附件自动回收默认关闭；管理员启用后，确认无引用且闲置七天，再进入七天回收站。
- 活跃上传、生成、处理和草稿附件受保护；未知引用的旧文件保守保留。不能仅根据目录名 `cache` 或文件年龄判断可删。
- 导出可选；本机默认清可重建缓存，登录、草稿、壁纸、设置和最近地址分别处理，不扫描用户下载目录。

## 服务端约束

- 统一 `/api/v1/resources` 统计、预检、任务、回收站与恢复接口；旧删除及间接删除入口接入同一生命周期服务。
- 回收状态同时约束列表、深链、搜索、分享、附件、RAG、协作和写入。
- 本人清空同时约束列表摘要、主消息、thread、pinned、unread、工具搜索、Socket 和通知；迟到响应、连续清空和撤销不恢复错误内容。
- 引用覆盖完整历史树、分享快照、回复、笔记、知识库、文件夹及模型资源，不能仅扫描当前 DOM。
- 清理任务幂等、有租约、可重试；数据库、物理对象和向量清理分别报告结果，不把隐藏或逻辑删除算作已释放字节。

## 阶段与验收

1. 本地真实页面：手机、横屏、桌面检查筛选、批量选择、影响预览和回收站。
2. 隔离后端：合成账号、临时数据库／文件／向量，验证权限、恢复、共享引用、并发、到期及任务重试。
3. 真实多人和多设备：本人清空隔离、旧客户端兼容、回复／置顶／搜索／通知无旁路。
4. 自管服务器副本演练：核对真实部署、完整备份、增量迁移、业务读取与备份恢复；生产副本不上传 GitHub。
5. 确认结果后再 PR、CI、自有镜像、生产切换及 APK 更新；不自动连接或清理生产。

保持官方 v0.12.2、数据库引擎、服务地址、存储与密钥；现有数据通过同卷继承及增量迁移继续使用。官方镜像回退不能代替迁移前完整备份。


## 本地修复验证记录（2026-10-21）

本记录仅覆盖隔离环境，不代表生产部署或全部功能验收完成。

- `scripts/test_resource_lifecycle.py`：40 项场景通过，使用临时 SQLite、真实路由、临时文件和 Chroma 向量；包括回收／恢复、共享引用、仅本人清空、故障重试及新增知识库清理场景。
- Socket 定向测试直接调用真实 handler，模拟认证会话和网络发送：验证聊天处理完整 viewer 作用域、回收笔记的协同加入／状态／更新／awareness 拒绝、迟到保存不覆盖正文。尚不等同于真实多进程 Socket.IO 客户端验收。
- 知识库新增验证：元数据向量在回收时隐藏、恢复后可用；清理故障保留原记录，重试后移除向量和当前模型引用，保留其他模型配置。未创建过的向量集合视为无待清理数据，不吞掉其他存储异常。
- 工作空间旧入口通过内部权限模式保留管理员／写协作者操作，执行时再次检查授权；资源管理 HTTP 参数不能开启该内部模式。验证授权撤销后任务拒绝执行，授权有效时可回收及完整恢复。
- 外部知识库的共享连接设置保持原样；本任务不删除远端知识库、连接密钥或共享连接。
- `scripts/test_resource_postgres.py`：隔离 PostgreSQL 增量迁移通过；这项结果仅证明迁移，不替代 PostgreSQL 下完整业务并发验证。
- `python -m unittest discover -s tests -v`：38 项基础测试通过；源码边界及 Python 语法检查通过。

仍需按发布前验收流程完成真实多人／多设备、任务重启与并发及生产副本演练。此轮没有推送、合并、镜像发布或 APK 发布。
