# 录音转文档

入口：**笔记 → 录音转文档／转写任务**。支持普通话课堂和会议录音文件；本功能不提供实时字幕。

## 配置与使用

1. 启用笔记，并在「管理设置 → 音频 → 语音转文字」配置服务端云 ASR。可复用 OpenAI 兼容地址、模型及 Key，或已有的 API Key 供应商连接；也可使用已有 Azure、Deepgram、Mistral 引擎。
2. 供应商连接必须允许当前用户使用；ChatGPT 套餐账号登录不提供 ASR 配额。未配置时不启动本地 Whisper。
3. 在录音页面上传文件，提交成功后可以关闭页面。上传本身必须保持页面打开。任务列表显示真实阶段及已完成分段数。
4. 完成后得到普通可编辑笔记；录音详情保留 ASR 原文快照。原文和编辑后的笔记可分别导出 TXT／MD。
5. 可选择服务端文字模型生成课堂笔记或会议纪要，另存为关联笔记。生成使用已保存的转写笔记，可能另行计费；原文不会被覆盖。
6. 选择当前文档和知识库保存文字快照；之后再次点击可更新同一份快照。此操作不授予原音频访问权。

默认限制：单文件 **500MB／2小时**，同时受更严格的 `rag.file.max_size` 限制。管理员可在录音页面调整大小、时长和 OpenAI 兼容 ASR 的返回格式。默认 JSON；仅在模型文档明确支持时选择 `verbose_json`／`diarized_json`。语言默认 `zh`。浏览器 WebM 缺少时长头时，会在时长上限内流式扫描确认，不直接拒绝有效录音；播放列表和网络音频引用不作为录音文件接受。

## 模型兼容与准确率

通用 OpenAI 兼容接入使用 `POST /audio/transcriptions`；修改模型名不能将该接口变成千问、豆包等厂商的专用异步录音协议。这些接口需要后续增加适配器的 submit/poll/cancel 实现。

模型只返回文字时仍正常生成文档。返回 `segments` 时保留有效的秒级 start/end 和 speaker/speaker_id，并换算为整段录音的时间。不同分段的说话人编号加分段前缀，不自动认定身份相同；可手工改名。导出细节不完整时回退完整原文，避免丢失文字。

当前建议将千问长录音、豆包或腾讯 ASR 作为试听候选。准确率需要用同一段课堂录音比较，尤其检查远距离收音、专业术语、噪声与多人重叠讲话；模型参数不是准确率保证。

## 任务、失败与存储

- 使用数据库持久化任务和分段结果，服务内后台 worker 领取任务。每个用户最多一个有效 ASR 租约；数据库唯一索引防止多进程重复领取。不需要额外 Redis。
- 每次仅用 ffmpeg 在磁盘生成一个最长10分钟的16kHz单声道64kbps片段；使用已有单片 STT 引擎，顺序提交并即时保存结果。上传探测、WebM扫描和转码共用每进程两个子进程的并发上限。不会把完整录音解码到内存。
- 必须提供 ffmpeg 和 ffprobe。服务在录音上传前检查依赖；Slim 变体如缺少它们，会明确拒绝使用本功能。
- 原录音存放在持久化的 `DATA_DIR/recordings/<job-id>/source`，仅通过鉴权接口访问；不发布公网音频 URL。备份应包含数据库及该目录，多副本需共用此数据卷。
- 音频默认保留。停止任务并等待在途请求结束后可单独删除；文档和原文快照仍保留，不能再回听或重试原音频。
- 权限和配置错误不自动重试。超时、重启或取消可能发生在上游已计费之后；界面提示手动重试。已完成分段保留；更换 ASR 模型、端点或返回格式后，重试会清空旧分段并重新转写。
- 租约过期的在途任务标为 interrupted，不自动重放不确定请求。请求取消后迟到的响应不得创建笔记。整理稿使用独立租约，失败不改变转写结果。

## 接口

`/api/v1/recordings` 提供 POST 上传（multipart + Idempotency-Key）、GET 分页列表；`/{id}` 获取详情；`/{id}/cancel`、`/{id}/retry` 控制任务；`/{id}/audio` GET 支持 Range 回听、DELETE 删除原音频；`/{id}/speakers` PATCH 保存显示名称；`/{id}/summary` POST 生成关联笔记（model、template、request_key）。

`/config` GET 返回可用性与有效上传限制；POST 仅管理员可修改录音限制和返回格式。原有 `/audio/transcriptions` 请求和返回保持兼容。任务只保存配置引用和端点指纹，不保存 Key。

## 验证与上线

`python scripts/test_provider_runtime.py` 包含隔离数据库、真实 HTTP 模拟 ASR、文件校验、50分钟分段、手动恢复、权限、取消、说话人、原音频删除、整理稿及知识库权限测试。模拟服务不计费，也不证明真实模型的识别准确率。

先通过前端 CI 并发布前端／Android，再将后端功能合入并由现有同步流程锁定前端、测试及发布镜像。配置真实 ASR 后，用一份课堂样本补做实际识别与费用验收。

任务删除与关联笔记：`DELETE /api/v1/recordings/{id}` 仅删除当前用户自己的任务记录，必须先删除原音频且没有排队、转写或整理请求在途；笔记和知识库文件不级联删除。配置接口 `can_delete_tasks` 用于前后端分阶段发布。删除原音频和删除任务记录是两个独立确认动作；关联笔记被回收不影响任务原文快照的读取。
